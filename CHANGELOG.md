# Changelog

All notable changes to **AttriSense AI** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-31

### Added
- **Predictive Attrition Risk Engine**: Random Forest Classifier evaluating 16 workforce parameters.
- **Explainable AI (SHAP TreeExplainer)**: Localized feature attribution mapping positive and negative risk factors.
- **Actionable Retention Recommendations**: Auto-generated HR intervention strategies.
- **Interactive "What-If" Risk Simulator**: Real-time policy sandbox.
- **Executive Analytics Dashboard**: Department heatmaps, tenure degradation curves, and performance matrices.
- **Async Export System**: Celery + Redis background workers generating executive PDF and Excel reports.
- **Enterprise Security**: OAuth2 JWT authentication, Passlib bcrypt hashing, fine-grained RBAC, and immutable audit logs.
- **Multi-Cloud Deployment**: Production manifests for Vercel, Railway, Neon PostgreSQL, Upstash Redis, and AWS S3.
